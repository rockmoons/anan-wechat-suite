# 常见问题与报错对照（anan-wechat-suite）

---

## 一、先做这几件事

1. **在豆包工作里第一次用 / 想改配置**：按 SKILL.md 的「★ 什么时候才引导配置（给 AI 的剧本）」走。
   **只有两种情况会走引导**：① 你说到「配置 / 设置 / 填密钥 / 换密钥 / 改配置」这几个词之一；
   ② 你要做发布类动作（发布 / 发到公众号 / 发出去 / 进草稿箱 / 推到草稿箱 / 群发）。
   其余动作（**抓 / 搜 / 写 / 改 / 图 / 排**）**一个字都不会提配置** —— 它们根本不需要密钥。
   AI 会一问一答把账号配好（想直发就配 AppID / AppSecret —— 个人号也能直发；不想配就走粘贴模式）；
   已经配过的，它会**先把当前配置打码显示出来，再问你要不要改**，不会从头重新问一遍。
2. 跑自检：`python scripts/selftest.py` —— 56 项离线检查，能排掉大半环境问题。
3. 看 `--help`：`python scripts/xxx.py --help` —— 每个脚本的参数都在里面。
4. **忘了怎么叫它**：说一句「**说明书**」（或怎么用 / 教程 / 帮助），它会把整份说明书
   （`references/QUICKSTART.md`）**原样贴出来**，不总结、不省略 —— 那份可以单独发给别人看。
5. **不知道从哪一步开始**：看你手上有的是什么 —— 只有主题 → 搜选题开始；给一个链接 → 从抓开始；
   给一篇稿子 → 从配图开始；只说「发出去」→ 只做发送。说 **全流程 / 一条龙 / 走一遍** 就走整条流水线。
   （详见 SKILL.md 第 0 节「怎么叫它干活：触发词 + 四种起点」。）

## 二、搜索（模块①）

| 你会看到 | 原因 | 怎么办 |
| --- | --- | --- |
| `搜狗返回了反爬/验证页（命中特征「访问过于频繁」）` | 触发搜狗风控 | 等几分钟到几小时；换关键词；别连续翻页 |
| `搜狗返回了页面，但没有解析出任何结果条目` | 关键词太冷门，或搜狗改了结果页结构 | 换更通用的关键词；若长期如此，是搜狗改版了，反馈给作者 |
| `N 条全部解析失败 —— 这条通道当前走不通` | 搜狗改了跳转实现，拼不出真实地址 | **这是如实报错，不是 bug**。搜索结果本身仍可用；把搜狗跳转链复制到浏览器打开，拿地址栏里的 `mp.weixin.qq.com` 链接再抓 |
| `预热失败（将继续不带 cookie 尝试）` | `v.sogou.com` 没返回 Set-Cookie | 不致命，脚本会继续。持续失败就加 `--no-warmup` |
| 解析出来的地址里有 `×tamp` 这种东西 | 是旧版本的 bug（把 `&times` 当成 HTML 实体转了） | 已修。确认你用的是本版脚本，重跑即可 |

**Q：搜索结果里的「发布时间」为什么有的没有？**
搜狗结果页的时间戳藏在页面脚本里，个别条目没有。缺失就留空，不编。

**Q：为什么搜到的文章标题和原文标题标点不一样？**
搜狗自己在摘要里做了标点归一（全角变半角）。以抓正文后的标题为准。

## 三、抓取（模块②③）

| 你会看到 | 原因 | 怎么办 |
| --- | --- | --- |
| `这不是微信公众号文章链接（域名是 xxx）` | 链接不是 `mp.weixin.qq.com` | 换正确的链接。**不要**随手加 `--allow-any-url` |
| `微信返回了拦截/错误页（命中关键词「环境异常」）` | 触发微信风控 | 停一会儿，减少批量，加大 `--delay` |
| `该内容已被发布者删除` | 文章被删 | 换链接，无解 |
| `页面里没有找到 id=js_content 的正文容器` | 分享卡片页 / 被删 / 需要登录 | 用浏览器打开确认能否正常阅读 |
| `正文解析为空……这是异常情况，请把链接报给作者排查` | 正文容器拿到了但没转出内容 | **这是报错，不是成功**。把链接报给作者 |
| `封面图下载失败（信息表里记原始链接）` | 防盗链或网络抖动 | 不影响正文；重跑一次通常就好 |
| `图片下载失败（保留原链接）` | 同上 | 正文里保留原始 URL，可重跑补齐 |
| 作者显示「未获取」 | 该公众号未单独署名 | 正常现象，不是故障 |
| 发布时间「未获取」 | 页面脚本变量缺失 | 少数文章会这样，如实标注 |

**Q：能抓到阅读量、点赞、在看、收藏、评论吗？**
**不能。** 这些数字是登录后在客户端由 JS 异步填的，静态页面里没有；脚本也不输出这些字段。
需要这类数据只能人工看，或走公众号后台 / 第三方数据平台。**不要向用户承诺能抓。**

**Q：能抓某个公众号的全部历史文章吗？**
不能。本技能只抓**已知链接**的单篇，没有列表 / 翻页接口。先用搜索模块找，或让用户提供链接清单。

**Q：能抓留言区内容吗？**
不能，留言不在静态页面里。

**Q：正文里出现「🎧 此处为公众号语音」「📇 此处为公众号名片」是什么意思？**
语音、视频、视频号、小程序卡片、内嵌 iframe 等在静态页面里拿不到内容，
脚本如实留占位说明，并把类型记进 `meta.json` 和 `富媒体清单.md`。这是**如实标注，不是故障**。

**Q：全档说能拿视频地址，为什么我这次一个视频都没解析出来？**
两种可能：① 这篇文章本来就没有视频；② 视频地址只存在微信客户端侧，静态页面里没有。
两种情况都会在 `富媒体清单.md` 里写明。**拿不到就是拿不到，脚本不会编一个地址出来。**

**Q：全档的 `原始页面.html` 有三四 MB，太占地方。**
它是离线留底，微信改版后还能回溯。不需要就用快档。

**Q：能一次跑几千篇吗？**
不要。会触发风控也会给对方服务器压力。几十篇一次、分批分时段，`--delay` ≥ 5。

## 四、写作与改写（模块④⑤）

| 你会看到 | 原因 | 怎么办 |
| --- | --- | --- |
| `找不到风格配置文件：.../references/styles.json` | 技能包没解压完整 | 重新解压；确认 references/ 目录存在 |
| `命中禁用表达：「赋能」` | 初稿里有该口吻明令禁止的词 | 按提示改掉，重跑 |
| `字数偏少：约 900 字，规则要求 1500-2500 字` | 篇幅不够 | 补内容，或用 `--words` 指定本次字数 |
| `个人口吻要求第一人称，全文「我」只出现 3 次` | 没按口吻写 | 改成第一人称，或换 `--style` |
| `商业洞察要求有「划边界」段，没找到` | 缺少「这个判断何时不成立」 | 补一段 |
| `第一行不是「# 标题」格式` | 初稿没按交付格式写 | 自己重写这一段，或在首行补 `# 标题` |
| `正文里有过程性标题（第 93 行，h2）：## 改了什么` | **正文文件里混进了「改动说明」** —— 那是给你看的，不是文章 | 一条命令挪走：`python scripts/guard.py 改写稿.md --fix`（会挪到 `改写稿.改动说明.md`）。★ 别用「先发出去再说」绕过：排版和发布都会把它当正文带走 |

**Q：那份「写作提示词」还要不要拿去别的工具写？**

**不用，默认路径是 AI 自己写。** 豆包工作（或任何会写字的 AI）读完 `article_writer.py` 渲染出来的
规则，**直接写出 `初稿.md`**，然后拿 `--check` 验收 —— 一步完成，不再绕「先出提示词、再交给别人写」。
那份提示词是**副产品**：想留档、想拿去别的工具（ChatGPT / Claude / 本地模型）写，都可以，它照样产出。
技能的价值是那套风格规则（`references/styles.json`），不是那份提示词。

**Q：`--check` 通过了就一定没问题吗？**
不是。它检查的是**可机检的硬规则**（字数、禁用词、结构要素），
事实准确性和逻辑质量它管不了。它是筛子，不是终审。

**Q：四种口吻为什么不写具体的真人名字？**
只描述特征、不点名真人，是为了避免「模仿某某」这类授权与人格权风险，
也避免把方法窄化成某一个人的风格。学的是结构和方法。

**Q：能用来把别人的文章改一遍发出去吗？**
**不能，那是侵权。** 改写只用于自己原创或已获得授权的素材。
引用要注明出处并附原文链接。本技能不提供任何规避查重的功能。

## 五、配图（模块⑥）

**Q：为什么 `illustration.py` 不直接给我图片？**
因为本技能**没有图像能力**，也不该有图像 API 的密钥。
它的交付物是**提示词 + 施工单**，出图由豆包工作完成。这一点 SKILL.md 里也是这么写的。

**Q：文章类型自动判断错了怎么办？**
用 `--type` 手动指定：`--type tutorial` 等，可选值见 `--list-types`。

**Q：提示词里的「不要出现文字」是必须的吗？**
强烈建议保留。图像模型生成的中文小字在手机缩略图上必然糊，标题交给公众号后台更靠谱。

**Q：图片怎么接回文章？**
见 `references/WECHAT-HTML-RULES.md` 第三节。核心一句：
**本地图片路径直接粘进公众号编辑器是无效的**，必须用浏览器打开 HTML、全选复制、再粘贴。

## 六、排版（模块⑦）

| 你会看到 | 原因 | 怎么办 |
| --- | --- | --- |
| `排版结果为空 —— 输入文件里没有可识别的内容` | 文件为空 / 编码不对 | 确认文件非空、是 UTF-8 |
| 提示 `带 BOM 已自动剥除` | 文件是记事本写的，带 BOM | 正常提示，已自动处理，不用管 |
| `提示：没识别到 H1 标题` | 首行不是 `# 标题` 格式 | 检查首行；本引擎已处理 BOM，剩下多半是格式问题 |
| `没有这个页面主题：xxx` | 主题名打错 | 用 `--list-themes` 看可用主题 |
| 粘到公众号后样式全没了 | 粘贴来源不对 | 见下条 |

**Q：粘到公众号后样式没了 / 图片裂了？**
两个原因：
1. 你复制的是 **Markdown 源文件**或**纯文本**，不是排版好的 HTML。要用 `--full-html` 产出后用**浏览器**打开再复制。
2. 图片是本地路径。公众号只认自己的图，必须走浏览器复制这一步让它自动上传。

**Q：列表整行都变粗了？**
这是公众号的经典坑：`<li>` 里以 `<strong>` 开头时，整行字重会被继承。
本引擎会自动补 `<span style="font-weight:normal">` 断开。
如果你看到整行变粗，说明用的不是本引擎产出的 HTML。详见 `references/WECHAT-HTML-RULES.md`。

**Q：支持哪些 Markdown 语法？**
h1–h6、粗体 / 斜体 / 粗斜体 / 删除线、行内代码、围栏代码块（带高亮）、
有序 / 无序 / 嵌套列表、任务列表、引用、表格、链接、图片、自动链接、分隔线。

**Q：能反向把 HTML 转回 Markdown 吗？**
不能，本技能不做这个。

## 七、发布（模块⑧）

| 你会看到 | 原因 | 怎么办 |
| --- | --- | --- |
| `!! 还没配置公众号 —— 不能发布。` | 这台机器上还没配置就跑了发布 | ★ **这是脚本故意拦住你的**（不是坏了）：没配置时它不会不声不响地降级成粘贴模式，而是把下一步打出来。照它说的做：跑 `python scripts/setup.py`；只想先排版就显式 `python scripts/publish.py 文章.md --mode paste` |
| `!! 公众号配置不完整 —— 不能发布。` | 配置里声明了「直发草稿箱」，但 AppID / AppSecret 没填齐 | 同上：跑 `python scripts/setup.py` 补齐（只换密钥用 `--update-secret`），或显式走 `--mode paste` |
| `未找到配置文件 config.json` | `--check` 体检时还没配过 | 跑 `python scripts/setup.py`，问几个问题就写好了（**不用手改文件**） |
| `这一格配的是「直发草稿箱」却缺少：appid、appsecret` | 配置声明走直发，但密钥没填 | **这是配置错误，脚本不会拿空密钥去试**。补密钥，或改用 `--mode paste` |
| `缺少封面图。公众号草稿要求 thumb_media_id 必填` | 没给 `--cover` | 加 `--cover images/cover.jpg`（jpg/png） |
| `封面图格式不支持：.webp` | 微信永久图片素材只收 jpg/png | 先转成 jpg |
| `!! 发布前闸门 A 拦下：正文里还有 N 张图没进微信图床 —— 发出去就是碎图。` | 正文里的 `<img src>` 还是本机路径 / 第三方外链，微信取不到。**这就是 2026-10-06「草稿箱里所有图都碎掉」那个 bug** | ★ **这是脚本故意拦住你的**：① 把那几张图转成 jpg/png（微信图片接口只收这两种，单张 1MB 以下）后重跑；② 图不想要了：`--drop-image 3,7`（按报错里的序号丢弃，日志会如实写出来）；③ 确认要带着碎图发：`--ignore-guard`（不推荐） |
| `!! 发布前闸门 B 拦下：正文里有**过程性标题**` | 正文文件里混进了「改了什么 / 修改说明 / 改动清单」。**这就是 2026-10-06「改动说明进了草稿正文」那个 bug** | 跑 `python scripts/guard.py 文章.md --fix`，把这一段挪到单独的 `.改动说明.md`；然后重跑发布 |
| `第 N 张图 ... 格式 webp 不在官方允许的 jpg/png 里` | 抓下来的图被 CDN 转成了 webp（抓取请求头带了 `image/webp`），而 `media/uploadimg` 只收 jpg/png | 正常情况下脚本会**自动回退用这张图的原始微信地址**（抓取时记在 `meta.json` 里），你什么都不用做。若是第三方外链图，就把它转成 jpg/png |
| `errcode=40009`（转存正文图时） | 单张图超过官方 1MB 上限 | 把那张图压到 1MB 以内再发（缩尺寸或降质量）。官方原话：「图片仅支持 jpg/png 格式，大小必须在 1MB 以下」 |
| 转存正文图时报 `errcode=40005` | 那张图不是 jpg/png（webp / gif / avif 都会被拒） | 同上：能回退原始微信地址就自动回退；回退不了就把图转成 jpg/png |
| `errcode=40164`（IP 白名单） | 本机出口 IP 不在白名单 | 跑 `python scripts/publish.py --myip` 拿到本机出口 IP，加进「微信开发者平台 → 选你的公众号 → 基础信息 → API IP白名单」（老路径「基本配置 → IP 白名单」已随平台迁移，找不到了）。也可以直接跑 `--probe`：报错里会**把要加的 IP 打出来**。家庭宽带 IP 会变，变了要重加 |
| `errcode=48001`（**建草稿**时） | 这个号确实没开通该接口（**不是**「个人号才这样」） | 2026-10-06 实测：个人订阅号（含未认证）与认证服务号**都能三步全过**；个别号确实没这个权限，**以 `--probe-full` 实测为准** → 确认没有就**改走粘贴模式**（不需要任何接口权限） |
| `errcode=48001`（**发布**时） | 这个号没有**发布**权限 —— 微信 2025 年 7 月起收回了**个人主体 / 企业未认证 / 不支持认证**这几类账号的调用权限 | **不是失败，是权限**：草稿已经建好了，去「公众号后台 → 草稿箱 → 点发表」。发之前先决定那个「群发通知」开关（见下）|
| `errcode=40013` / `40125` | AppID / AppSecret 不对 | 去「微信开发者平台 → 首页/服务号 → 选公众号 → 基础信息」核对；老路径「设置与开发 → 基本配置」已迁移打不开。改正**不用打开文件**：重跑 `python scripts/setup.py`，或只换密钥跑 `python scripts/setup.py --update-secret` |
| `errcode=45009` | 接口调用超频 | 等一会儿再试 |
| `网络请求失败` | 本机网络问题 | 检查能不能访问 `api.weixin.qq.com` |

**Q：我怎么知道草稿箱里那篇的图是不是好的？**

两条路：

1. **跑一次端到端自检**（推荐，改完流水线必跑）：

   ```bash
   python scripts/e2e_test.py
   ```

   它会真的抓一篇带图文章 → 改写 → 排版 → 把正文图转存到微信图床 → 建一篇标题带
   **【E2E 自检】** 的草稿 → 再用 `draft/get` **把草稿读回来**，逐张验 `img src` 是不是都在腾讯图床域上。
   还会自带两条反证：往正文里塞「## 改了什么」、和一份「图还是本机路径」的稿子，**跑发布必须被拦下来**。

2. **人工看一眼**：草稿建好后去公众号后台「草稿箱」打开那篇，图能正常显示就是好的。
   （碎图在编辑器里会显示成破图占位。）

**Q：它会替我把文章发出去（发布）吗？**

**会，但要你点头。** 发布这一步是**两步走**，不许一条命令闷头发出去：

```bash
# 第 1 步：建草稿 + 把「标题 / 封面 / 摘要」报出来 —— **不会发布**
python scripts/publish.py 文章.md --mode api --cover images/cover.jpg --publish
# 第 2 步：你看过上面三样、说「发吧」，才跑这条（复用同一个草稿，不会重复建）
python scripts/publish.py --publish-go <第 1 步给出的 media_id>
```

- 发出去**不可撤销**，所有关注者都能看到 —— 这就是要先看一眼的原因（自检里有一项盯着：
  只跑 `--publish` 时，发布接口**一次都不能被调到**）。
- 认证号会走通，脚本随后把**公开链接**给你；链接一时取不到就如实说取不到，**绝不编一个**。
- **没发布权限的号**会如实报 `48001`，并告诉你后台怎么发（见上表那一行）。

**Q：会帮我群发（推送给粉丝）吗？**

**不会，而且以后也不会加。** 微信有群发能力、也需要认证，但这个技能**有意不碰**：

1. **群发 = 打扰粉丝** —— 一条发出去，所有关注者的手机都会响；
2. **不可撤销** —— 发错了收不回来；
3. **一天只有 1 次额度** —— 用掉了就没了，不该交给脚本去赌。

这不是「暂时没做」，是**长期承诺**：自检里有一项扫**所有脚本**，任何一个文件出现群发接口就直接判失败。

**Q：我自己在后台点「发表」，有什么坑？**

有一个，而且很容易踩 —— 弹窗里那个「**群发通知**」开关：

| 开关 | 效果 |
| --- | --- |
| ✅ 开启（**默认**） | 推送给粉丝，**一天只能 1 次** |
| ❌ 关掉 | 不推送，只上公众号主页，**不限次数** |

**它默认是开的 —— 不想打扰粉丝，记得手动关掉。**
（微信改版把「群发」和「发布」合并成了「发表」，就是靠这个开关区分。）

**Q：我没配置，为什么直接跑 `publish.py` 不给可粘贴 HTML 了？**

因为**发布是要密钥的动作，脚本不再替你默认降级** —— 不声不响地给一个 HTML，
你就不会知道还有「配好密钥就能直发草稿箱」这条路。没配置时它会把下一步直接打在屏幕上：

```text
!! 还没配置公众号 —— 不能发布。
   这一步需要 AppID / AppSecret（或先选粘贴模式）。

   跑这条开始配置：
     python scripts/setup.py
   （或告诉我「配置」，我来一步步问你）
```

- **想配置**：跑 `python scripts/setup.py`（问几个问题，**不用手改文件**）。
  在豆包工作里也可以直接说「**配置**」，AI 会一步步问你。
- **只想先排版、自己粘**：显式加 `--mode paste` —— 这条路不需要任何密钥，
  **永远可用**（写稿 / 改写 / 配图提示词 / 排版全自动，只有最后一步手动粘）。
- **其余模块不受影响**：抓 / 搜 / 写 / 改 / 图 / 排 **根本不读配置**，没配置照样跑，
  一个字都不会提配置。

**Q：我在微信后台**重置了 AppSecret**（或怀疑密钥泄露了），怎么填进去新的？**

不用打开任何文件，跑一条命令：

```bash
python scripts/setup.py --update-secret
```

它只问 AppSecret，账号名 / AppID / active 一个字都不动。也可以整条重跑
`python scripts/setup.py`：问到 AppID / AppSecret 时**直接回车 = 保持现在的值**，
想换就输入新值。填完跑 `python scripts/publish.py --probe` 验一次。

**密钥安全三条**：不要发给任何人、不要提交 git、怀疑泄露就去
微信开发者平台 → 选你的公众号 → 基础信息 → 开发密钥 →「重置」。
本技能的请求**只发往 `api.weixin.qq.com`**（脚本里硬校验，其它域名一律拒绝），不中转、不外发、不进日志。

**Q：我在公众号后台翻遍了也找不到 AppID / AppSecret，网上教程说的路径点不进去？**

因为**那个路径已经没了**。微信的密钥页与接口权限页 **2025-12-01 起已迁移到「微信开发者平台」**，
老教程里的「公众号后台 → 设置与开发 → 基本配置」2025-12-01 起已迁移，打不开了。真实路径是：

**怎么进这个平台（2026 实测走通，两个入口任选）：**

```text
入口 A：打开 https://mp.weixin.qq.com/ 用【企业管理员】的个人微信扫码登录
        → 设置与开发 → 开发接口管理（只剩一张「开发管理模块迁移通知」）
        → 点通知里的「微信开发者平台」链接
入口 B：直接打开 https://developers.weixin.qq.com/platform   ← 更短，建议收藏
        （同样用管理员微信扫码登录）

进去之后（六步）：
⓪ 打开 https://mp.weixin.qq.com/ —— 用【企业管理员】的个人微信扫码登录
   ⚠️ 必须是这个号的管理员；普通运营者的微信看不到下面那个入口
① 公众号后台 → 设置与开发 → 开发接口管理（老路径，只剩一张迁移通知）
   → 点通知里的「微信开发者平台」链接
   ★ 到了平台页必须点「前往控制台」按钮 —— 最容易漏的一步，不点进不去控制台
② 顶部「我的业务与服务」→ 下拉框 → **按号型点对应的那一项**：
     企业注册的服务号 → 点「服务号」
     个人主体注册的号 → 点「公众号」         ← 个人号在这里（别去「服务号」里找）
   ⚠️ 「公众号」和「服务号」是**两个不同的菜单项**，点错了里面找不到你的号（找不到就先看另一项）
   ⚠️ 有多个号时还要选对具体哪一个（可能显示成「服务号 4」这种，选错=白配）
③ 选对了才会出现标题「首页 / 服务号」**或**「首页 / 公众号」，以及那一排 tab：
   基础信息 / 开放能力 / 接口管理 / 绑定关系 / 授权关系
④ 停在【基础信息】：
     AppID                      第一行
     开发密钥 → AppSecret        右侧「启用」或「重置 / 冻结」（只显示一次）
     开发密钥 → API IP白名单     AppSecret 下面一行
⑤ 接口权限不在这一页，在「接口管理 → 接口权限与额度」（下拉框只有 5 类）
```

**这三样都在同一页上**（AppID 在「基础信息」第一行；AppSecret 和它下面一行的 API IP白名单
在「开发密钥」区域），不用跑去别的地方。AppSecret 右边显示「启用」＝从没启用过，点它拿新密钥；
显示「重置 / 冻结」＝已经启用过了，**记得密钥就什么都不用动**，忘了才点「重置」。
没有启用过 AppSecret 时，API IP白名单那一行是灰的、点不了。

**但先等一下**：如果你用的是**个人订阅号**，好消息是 —— **2026-10-06 实测：个人订阅号同样能直发草稿箱**
（个人主体、认证状态「暂未认证」，跑 `--probe-full --with-draft` 三步全过：
换 token ✅ / 上传永久素材 ✅ / 建草稿 ✅）。所以个人号**也可以去把这三样配起来**，
配好了就能全自动到草稿箱；不想配就继续走粘贴模式（永远可用的保底）。

> 早前版本里写过「个人订阅号没有开发者接口，只能粘贴」——**那是错的**，已按 2026-10-06 的实测结果改正（见上）。

**「粘贴模式」永远可用，是主动做的保底，不是微信给的**：就算你的号能调接口，这条路也一直开着 ——
（排版 → 浏览器复制 → 粘进编辑器）是我们自己做好并验证过的。写稿 / 改写 / 配图提示词 / 排版
**全自动**，只有最后一步「复制粘贴 + 点发布」是**手动**的 —— 不是功能少，是最后一步从自动变手动。

**Q：IP 白名单要加哪个 IP？学员怎么知道自己的 IP？**

```bash
python scripts/publish.py --myip
```

它打印本机出口 IP（**单独一行，方便双击复制**），并告诉你去哪个页面加。两条路都试：
先用已配置的密钥调一次 token 接口（白名单没配好时微信会把 IP 写进 40164 报错里），
拿不到再问公开 IP 服务；**两条都拿不到就如实说拿不到**，并给出替代办法
（浏览器搜「IP」、或跑 `--probe` 让微信报出来），**绝不会编一个 IP 给你**。

**加白名单这一步必须你本人登录微信页面操作** —— 脚本替你做不了，也不该替你做，
这是微信的安全设计（能自动替你加，就能自动替别人加）。入口有两个：
主路径「基础信息 → API IP白名单」；那页找不到，就看「开发密钥」区域里的 API IP白名单
（就在 AppSecret 下面一行）。加完跑 `python scripts/publish.py --probe` 验证。

家庭宽带 IP 会变，变了要重新加。不想折腾就退回粘贴模式：它不碰任何接口，不需要白名单。

**Q：`--check` 说「这一格存着密钥，但当前标着 paste」是什么意思？**

说明这一格**存着 AppID / AppSecret，但路线标成了粘贴模式**（你当时选了 [2] 粘贴）。
默认就不会走接口，但密钥**没有被删掉**。想走直发，两种办法：

- 就这一次：跑文章时加 `--mode api`；
- 长期改过来：`python scripts/setup.py` → 选 [1] 直发草稿箱（一个文件都不用打开）。

`type` 里如果是 `service` / `personal` 这种旧词汇，脚本会按新口径处理并在 `--check` 里注明
（`service` → 直发；`personal` → 未指定，仍按有没有密钥判断）—— **老配置不需要动，也不会丢数据**。

**Q：`--probe` 通过了，是不是就能直接发文章了？**

**不是。** `--probe` **只验第 1 步**（换 access_token = AppID / AppSecret / IP 白名单）——
它过了只说明「密钥和白名单没问题」，**不代表你这个号能传素材、能建草稿**。

要验到底：

| 命令 | 验到哪一步 | 留下什么 |
| --- | --- | --- |
| `python scripts/publish.py --probe` | 只验第 1 步：换 token | 什么都不留 |
| `python scripts/publish.py --probe-full` | 第 1 步 + 第 2 步：真上传一张测试小图（验 `material/add_material`） | 图片素材库里多一张小图，可删 |
| `python scripts/publish.py --probe-full --with-draft` | 再加第 3 步：建一篇【测试】草稿（验 `draft/add`） | 草稿箱多一篇，看完自己删 |

拿到 **`errcode=48001`** 就是**这个号确实没有这个接口权限** —— 别怀疑是脚本的问题，
改走粘贴模式即可（`--mode paste`，不需要任何接口权限）。

**Q：会帮我把文章群发出去吗？**
**不会。** 脚本里**没有任何群发接口**，跑完只会在草稿箱里放一篇，发布永远由你自己点。
（自动群发一条错内容，代价太大。）

**Q：我的 AppSecret 会被发到哪里？**
**只会发往 `api.weixin.qq.com`。** 脚本里有硬校验，
任何其它域名（包括 localhost 上的中转服务）都会被直接拒绝并抛错。
这是本技能与某些「远程中转发布」方案的根本区别——**不做中转**。

**Q：access_token 会存在磁盘上吗？**
不会。只在内存里用，用完即弃。日志里也不会出现完整密钥（一律打码）。

**Q：`config.json` 会被打进 zip 包吗？**
不会。它在 `.gitignore` 里，打包脚本也排除了它。
自检里有一项专门检查这事。

## 八、环境相关

- 需要 **Python 3.8+**，脚本**零第三方依赖**，`python -S`（不加载 site-packages）也能跑。
- 需要能访问 `mp.weixin.qq.com`、`mmbiz.qpic.cn`、`weixin.sogou.com`；
  只有发布需要 `api.weixin.qq.com`。
- 输出全程 UTF-8；CSV 带 BOM，Excel 双击不乱码。
- **控制台中文乱码**：脚本会自动把 stdout/stderr 设为 UTF-8；如仍乱码，用 `chcp 65001` 或换 Windows Terminal。
- **输出目录**默认是**当前工作目录**下的 `output`，不是脚本所在目录。建议始终用 `-o` 明确指定。
