# 说明书

**阿南 · 微信公众号全流程工作台**

> 这一份可以**单独发给别人看** —— 不装技能也读得懂它在干什么。
> 装在豆包工作里的时候：**说一声「说明书」，它会把这一整份原样贴出来**（不总结、不省略）。

它把公众号从「找一个好选题」到「文章进了草稿箱」串成一条流水线，八个模块：
**搜爆款 · 抓文章（快 / 全）· 写初稿 · 改写 · 配图提示词 · 排版 · 发布**。
零第三方依赖，密钥只存在你自己电脑上。

---

## ① 怎么叫它干活（触发词总览）

| 你想干的事 | 你就这么说 |
| --- | --- |
| 配账号 / 换密钥 | **配置** / 设置 / 填密钥 / 换密钥 / 改配置 |
| 从选题一路做到发布 | **全流程** / 一条龙 / 走一遍（或「帮我从选题到发布走一遍」） |
| 看这份说明书 | **说明书** / 怎么用 / 教程 / 帮助 |
| 只做其中一步 | 直接说你要做什么（见下面第 ③ 块） |

**不用背触发词。** 「把这篇文章发出去」「把这篇整理一下」「排版发到公众号」这类日常说法它都认。
只有一件事要分清：**「帮我写一篇 XX」= 只写一篇初稿给你看**，它不会顺手去搜选题、排版、发布 ——
想要一整条，就明说「**全流程**」。

## ② 四种起点：你手上有什么，它就从哪开始

| 你手上是 | 它从哪开始 | 走完全程长这样 |
| --- | --- | --- |
| 只有一个主题（并且说了「全流程」） | 搜选题 | 搜选题 →（**你挑一篇**）→ 抓 → 写 → 配图 → 排版 → 发 |
| 一个链接 | 抓 | 抓 →（改写）→ 配图 → 排版 → 发 |
| 一篇稿子 | 配图 | 配图 → 排版 → 发 |
| 只想发出去 | 只发送 | 只做发送（排版 + 发布） |

- **「（你挑）」是硬节点**：它会把候选列出来让你挑，**不会替你挑**。
- **「（改写）」是可选**：链接是别人的文章才需要改写，而且只用于你自己写的、或已获授权的素材。
- **每一步做完都会告诉你产物存在哪**；也可以中途停下 —— 后面每一步都能单独跑。

## ③ 八个模块：你说什么 → 它做什么

| # | 模块 | 你就这么说 | 它做什么 |
| --- | --- | --- | --- |
| ① | 搜爆款 | 搜一下 XX 的爆款 | 爬搜狗微信找选题，列候选给你挑（可顺带把搜到的正文抓下来） |
| ② | 抓文章（快） | 把这篇抓下来 | 正文 + 图片 + 封面 + 信息表 |
| ③ | 抓全套（全） | 抓全套 / 存个完整档 | ②的全部 + 富媒体清单 + 原始页面存档 |
| ④ | 写初稿 | 帮我写一篇 XX | 按四种口吻里的一种**直接写出初稿**（那份写作提示词是副产品，可留档、可拿去别的工具用） |
| ⑤ | 改写 | 把这篇改写成我的口吻 | 三种模式：结构重组 / 语言改写 / 加真实感 |
| ⑥ | 配图 | 配几张图 | 出配图提示词与施工单（**它不出图**，出图在豆包工作里做） |
| ⑦ | 排版 | 帮我排版 | Markdown → 公众号可直接粘贴的全内联样式 HTML |
| ⑧ | 发布 | 放进草稿箱 / 存草稿 | 排好版后存进**草稿箱**，只有你自己看得见；没配账号会先拦下来，告诉你跑哪条命令配 |
| ⑧ | 发布 | 发布 / 发表 / 发出去 | **连发布一起做**（认证号才行）：但**先**把标题 / 封面 / 摘要给你看，你点头才发；发完给公开链接 |

**四种口吻**：商业洞察 · 爆款结构 · 个人口吻 · 财经深度。
**三种改写**：结构重组 · 语言改写 · 加真实感。
**排版主题**：anan（默认）· ink · warm · forest · night。

## ④ 常见问题

**Q：每次都要配置吗？**
不用，**配一次就够**。只有你说「配置」这类词、或者你要做发布类动作
（发布 / 发到公众号 / 发出去 / 进草稿箱 / 推到草稿箱 / 群发）时，它才会问配置。

**Q：我只想排版，会不会被追问密钥？**
不会。**抓 / 搜 / 写 / 改 / 图 / 排 一个字都不会提配置** —— 这些动作根本不需要密钥。

**Q：自动存进草稿箱，算自动发布吗？**
**不算 —— 草稿箱 ≠ 发布。** 三档要分清：

| 档 | 走的接口 | 谁能看到 | 它怎么做 |
| --- | --- | --- | --- |
| 存草稿 | `draft/add` | **只有你自己**在后台能看到 | ✅ 做（默认就停在这） |
| 发布 | `freepublish/submit` | **所有关注者**都能看到（不可撤销） | ✅ 做，但**先给你看标题/封面/摘要，你点头才发** |
| 群发 | 微信的群发能力 | 直接**推送到粉丝手机** | ❌ **永远不做**（见下一条） |

「自动存进草稿箱」**不等于**「自动发布」—— 草稿箱里那篇只有你看得见。
真发布要过两道：**第一步建草稿并把三样报给你看，第二步你确认了才发出去**，
所以不存在「它自己闷头把文章发出去了」这种事。
（订阅号每天群发次数有限，推草稿箱不限量 —— 可以一天备好几篇攒着发。）

**Q：它会替我群发吗？不会。**
微信确实有群发能力，但**这个技能有意不碰**，而且以后也不加。三条理由：
① **群发 = 打扰粉丝**（所有关注者手机都会响）；② **不可撤销**（发错了收不回来）；
③ **一天只有 1 次额度**（用掉了就没了，不该交给脚本去赌）。

**你要自己发的时候，这里有一步最容易踩**：在后台点「发表」时，弹窗里有个「群发通知」开关：

| 开关 | 效果 |
| --- | --- |
| ✅ 开启（**默认**） | 推送给粉丝，**一天只能 1 次** |
| ❌ 关掉 | 不推送，只上公众号主页，**不限次数** |

**它默认是开的 —— 不想打扰粉丝，记得手动关掉。**

**Q：没有发布权限怎么办？**
微信 2025 年 7 月起收回了这几类账号的调用权限：**个人主体、企业未认证、不支持认证**。
真去发布时它**不会假装成功**，会如实告诉你「这个号没有发布权限」—— 同时草稿已经建好了，
你去「公众号后台 → 草稿箱 → 点发表」就行（记得看上一条那个开关）。

**Q：密钥安全吗？**
AppID / AppSecret **只存在你自己电脑的配置文件里**，不外发、不上传、不进日志；
请求**只发往 api.weixin.qq.com 这一个官方域名**（脚本里硬校验，其它域名一律拒绝）。
怀疑泄露，就去微信开发者平台重置一次，再跑一遍配置命令换掉。

**Q：个人订阅号能用吗？**
能。**2026-10-06 实测：个人订阅号（个人主体、未认证）三步全过**（换 token → 传素材 → 建草稿），
认证服务号当然也能。个别号确实没有接口权限的话，脚本会**如实报出来**；
而且随时可以退回「**粘贴模式**」：排版自动，最后一步你自己复制粘贴，不需要任何接口权限。

**Q：忘了怎么说？**
就说「**说明书**」—— 或者「怎么用」「教程」「帮助」，一样。
