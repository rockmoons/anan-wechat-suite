# 四种口吻与三种改写模式（人读版）

> **权威在 `references/styles.json`。** 本文件是给人看的同一套规则，
> 方便讲课时直接念。两者不一致时**以 styles.json 为准**——
> 脚本读的是它，`--check` 校验的也是它。

---

## 设计原则

1. **四种口吻只描述「特征」，不点名任何真人。** 想学谁的路子，学的是结构和方法，不是名字。
2. **每种口吻都由三件套定义：结构骨架 + 硬规则 + 禁用表达清单。** 缺一件就不算完成。
3. **禁用清单是可执行的检查项，不是修辞建议。** 写完逐条对照，脚本也会帮你扫。

为什么禁用清单这么重要：写「要接地气、要有网感」这种要求，模型无法执行也无法验收。
写「不许出现赋能 / 抓手 / 闭环」才能真的被检查。**可执行的约束才是约束。**

---

## 一、商业洞察（`business-insight`）

**一句话**：从一件具体的商业小事里，抽出一条能复用的判断。

**什么感觉**：冷静、克制，像在跟同行复盘，不像在演讲。先给事实再给判断，判断必须能一句话说完。
喜欢用跨行业类比来验证同一个机制。

### 结构骨架（7 步）

1. 现象切入：一个具体到能看见数字的场景（谁、在哪、做了什么、结果如何）
2. 提出问题：这背后到底是什么在变？
3. 给出判断：一句话观点，独立成段，加粗
4. 论证一：拆开一个案例的内部机制（为什么它会这样）
5. 论证二：换一个行业，验证同一机制是否成立
6. 划边界：这个判断在什么条件下不成立、会怎么失效
7. 落到行动：读者明天可以做什么，给 2-3 条可执行建议

### 硬规则（5 条）

- 核心观点必须能用一句话说完，且这句话要单独成段
- 每个论点后面必须跟一个具体案例或一个具体数字，二者至少有一个
- 必须有「划边界」那一段，没有边界感的判断不算洞察
- 结尾必须落到可执行动作，不能停在感慨
- 全文 1500-2500 字

### 禁用表达（6 条）

点名任何真人并要求模仿其风格 · 话题标签（#xxx）· 大段 emoji 装饰 ·
「欢迎在评论区留言」这类求互动结尾 ·
赋能 / 抓手 / 闭环 / 颗粒度 / 打法 / 心智 / 组合拳 等空泛黑话 ·
「众所周知」「不言而喻」这类不需要论证就下结论的说法

## 二、爆款结构（`viral-structure`）

**一句话**：标题先赢，前三秒留住人，靠节奏和密度读完。

**什么感觉**：短句、强节奏，读起来像有人在推着你往前走。信息密度高，几乎每段都有新东西。
有明确的「信息差」——读者看完比看之前多知道一件事。

### 结构骨架（5 步）

1. 标题矩阵：按 5 个维度各写一个候选（悬念 / 痛点 / 反直觉 / 利益 / 强情绪），再挑一个
2. 开头：从「提问 / 场景 / 数据 / 故事 / 反差」五法里选一种，前三行必须出现钩子
3. 主体：从「总分总 / 清单 / 叙事 / 对比」四模式里选一种，不混用
4. 每个小标题都要能单独当一条朋友圈发出去
5. 结尾：给一个明确的下一步动作，而不是总结全文

### 硬规则（5 条）

- 每个自然段不超过 4 行（手机屏幕上不超过 4 行）
- 每 300 字内必须出现一个小标题或一次明显转折
- 至少有一处「信息差」，是读者在别处不容易看到的
- 全文至少 3 个可直接截图传播的短句
- 全文 1200-2000 字

### 禁用表达（5 条）

标题与正文不符（标题承诺的东西正文必须真的给）·
震惊 / 速看 / 删前速存 / 不转不是中国人 这类强骗点击词 ·
没有信息量的情绪词堆砌（绝了、炸了、破防了 连用）·
「据说」「听说」这类没有出处的事实陈述 · 点名任何真人并要求模仿其风格

## 三、个人口吻（`personal-voice`）

**一句话**：随意感优先于口语化——像真人随手写的，不像在表演亲切。

> 这条最容易做错。「口语化」用力过猛会变成「家人们谁懂啊」，
> 而「随意感」是**节奏不均匀 + 细节具体 + 敢说不确定**。

**什么感觉**：第一人称，敢说自己的判断，也敢说自己的不确定。
长短句交错，节奏不均匀（均匀本身就是 AI 味）。有具体细节：时间、地点、数字、当时的原话。

### 结构骨架（5 步）

1. 开头 3 段之内必须出现钩子（一个具体的麻烦、一个反常识的发现）
2. 每 4-6 段插一个小标题，给读者一个喘气点
3. 至少写 1 组 if/then（如果你也遇到 X，那就试试 Y）
4. 中间允许跑题一次，但要能绕回来
5. 结尾必须带 CTA，说清希望读者做什么

### 硬规则（5 条）

- 全文第一人称，出现「我」的次数不少于 8 次
- 至少主动承认一次自己的不确定或一次踩过的坑
- 至少 3 处具体到不可替换的细节（不是「有一次」而是「上周三下午」）
- 相邻三段的句式不能同构
- 全文 1000-1800 字

### 禁用表达（5 条）

赋能 / 抓手 / 闭环 / 矩阵化 / 全方位 等空泛大词 ·
综上所述 / 毋庸置疑 / 不难发现 等学术套话 ·
连续三段使用同一种句式开头 ·
「家人们」「宝子们」这类强行套近乎的称呼 · 点名任何真人并要求模仿其风格

## 四、财经深度（`finance-depth`）

**一句话**：像个在市场里待了十几年的老朋友，把钱的流向讲清楚。

**什么感觉**：讲人话，不堆术语；非要用的术语，第一次出现就顺手解释。
先讲利益结构：谁赚、谁亏、谁买单。敢亮自己的判断，也敢说自己在什么情况下会错。

### 结构骨架（5 步）

1. 当期事件：最近发生了什么（时间、主体、数字）
2. 拆利益结构：这条链上谁赚钱、谁承担风险、谁最后买单
3. 历史对照：以前出现过类似的事吗，结局如何
4. 对普通人的含义：这件事跟读者的钱、工作、选择有什么关系
5. 风险提示：什么信号出现，说明这个判断该推翻

### 硬规则（5 条）

- 必须明确区分「事实」与「我的判断」，判断句要有标记（我认为 / 我的判断是）
- 必须写「什么情况下我错了」这一段
- 所有数字标明来源，或明确说明是估算
- 必须包含一段风险提示，不得只讲机会
- 全文 1500-2500 字

### 禁用表达（5 条）

荐股、推荐具体买卖标的 · 必涨 / 稳赚 / 暴富 / 抄底 / 翻倍 这类收益承诺 ·
内幕消息 / 独家消息 这类暗示信息优势的说法 ·
把可能性说成确定性（「一定会」「必然会」）· 点名任何真人并要求模仿其风格

## 五、三种改写模式

| 模式 | key | 一句话 | 动作 | 硬规则 |
| --- | --- | --- | --- | --- |
| 结构重组 | `restructure` | 内容不变，把骨架换一副 | 段落重排 / 拆合、叙事角度转换、论据重组 | 不新增事实；逻辑自洽；能说清新旧结构差在哪 |
| 语言改写 | `rewrite` | 骨架不变，把话说得像人话 | 删意义膨胀句、去虚假权威、去广告语气、去 AI 高频词 | 不改事实与结论；不丢限定条件；**字数不膨胀** |
| 加真实感 | `humanize` | 补真人痕迹 | 第一人称、承认不确定、长短句交错、加具体细节 | 细节必须真实或标注为示例；不确定性不超过 3 处；不把专业内容口语化到失真 |

### 「语言改写」的四个动作细说

- **删意义膨胀句**：把「极大地提升了整体的运行效率」压成「快了一倍」
- **去虚假权威**：删掉没有出处的「研究表明」「业内普遍认为」
- **去广告语气**：删掉「重磅」「颠覆」「史上最强」
- **去 AI 高频词**：值得注意的是、综上所述、在当今时代、随着……的不断发展

`--check-rewrite` 会比对原文与改写稿：数字有没有凭空多出来、字数有没有膨胀、有没有引入红线词。

## 六、合规红线（四种口吻与三种模式共同遵守）

- 改写只用于**自己原创**或**已获得授权**的素材。
- **不得**用于搬运他人原创文章后冒充原创发布——这是侵权，平台有原创声明与投诉机制。
- 引用他人内容必须注明出处并附原文链接。
- 本技能**不提供**「降重」「伪原创」「规避查重」这类功能，也不接受这类指令；
  做的是**换风格重写**，不是绕过检测。

## 七、怎么用这一套

```bash
python scripts/article_writer.py --list
python scripts/article_writer.py --style personal-voice --topic "选题" -o prompt.md
# 你（豆包工作）直接按 prompt.md 里的规则写出 初稿.md（提示词本身是副产品）
python scripts/article_writer.py --check 初稿.md --style personal-voice
```

**规则和校验是同一套。** 改了 styles.json，提示词和检查项会一起变，
不会出现「文档写了一套、实际跑的是另一套」。
